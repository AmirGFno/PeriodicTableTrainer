نصب نسخهٔ ویندوز Periodic Table Trainer

۱. فایل PeriodicTableTrainer-Setup-<version>.exe را اجرا کنید.
۲. درخواست مجوز Windows را تأیید کنید تا برنامه در Program Files نصب شود.
۳. نصب‌کننده میان‌بر دسکتاپ و منوی Start را می‌سازد.

فایل‌های برنامه در پوشهٔ نصب قرار می‌گیرند. داده‌ها و WebView profile در پوشهٔ کاربر در %LOCALAPPDATA%\PeriodicTableTrainer ذخیره می‌شوند و با نصب مجدد یا حذف برنامه پاک نمی‌شوند.

برای خطای قدیمی Python DLL، نصب‌کنندهٔ جدید را اجرا کنید؛ به‌روزرسانی درون‌برنامه‌ای فقط HTML را جایگزین می‌کند و EXE را تغییر نمی‌دهد.
